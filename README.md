# arbiter-activity-monitor

Native macOS system and AI workload monitor with process Quit / Force Quit, agent token usage and a local LLM benchmark (Swift 6, SwiftUI, macOS 14+).

The app lives in [`app/`](app/). Start with its
[README](app/README.md) for build, run and capability notes, and
[AGENTS.md](app/AGENTS.md) before changing code.
